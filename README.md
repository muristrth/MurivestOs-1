## THE SALES ACQUISITION FRAMEWORK

### Don't "Sell Property" — Sell These:
- **Yield:** "This asset yields 9.3% — outperforming most markets"
- **Positioning:** "Last Grade A office at this price point in CBD"
- **Opportunity Timing:** "Window closes in 30 days — institutional interest building"
- **Upside Potential:** "Repositioned, yield moves from 6% to 11%"

### Control Every Interaction:
- "Let's schedule a call this week" (not "Let me know when you're free")
- "Let's get NDA signed so I can share the full IM" (not "Would you like to see more?")
- "Let's arrange site visit — when are you available?" (not "Maybe we can visit sometime")
- "Let me send you the LOI so we can start moving" (not "Would you consider an LOI?")

### Create Competition (Even If Early):
- "We have multiple parties reviewing this asset currently"
- "The owner has asked me to advance discussions with serious buyers only"
- "A decision is expected before end of month"
- "This is the last asset in this portfolio available at this price"
